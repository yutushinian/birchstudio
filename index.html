THE PROCESS · 专属定制流程

六步，拥有一串自己的白桦

从沟通需求到净化交付，每一串手串都认真对待。定制遵循三阶递进逻辑：先判身强身弱 → 再定补泄方向 → 后调时令卦象（文化象征体系，供参考）。

1

沟通需求

用途、预算、场合与风格偏好——先聊清楚，再开始。

2

生辰分析

3

选石搭配

相生相克 · 五行关系

相生 木→火→土→金→水→木
相克 木→土→水→火→金→木

相克的水晶一般可以一起戴，能量取向不同而已；讲究的话分左右手佩戴即可。

五行配比 · 入门参考

偏金 → 白水晶 · 金发晶 · 钛晶 偏木 → 绿幽灵 · 东陵玉 · 孔雀石 偏水 → 黑曜石 · 海蓝宝 · 青金石 偏火 → 紫水晶 · 粉晶 · 草莓晶 偏土 → 黄水晶 · 虎眼石 · 蜜蜡

「缺什么补什么」为入门简化说法；严谨做法需结合八字整体平衡与喜用神判断，某五行过旺时反而不宜再补。对应关系属传统文化与民俗象征体系，供文化体验参考。

佩戴讲究「左进右出」：左手为接收端，取增益意象（粉晶 · 黄水晶 · 绿幽灵 · 月光石）；右手为释放端，取护身安定意象（黑曜石 · 黑碧玺 · 茶晶）。仅作饰品则左右皆可，舒适为先；叠戴建议不超过 3 种，主次分明、方向一致。

阴阳消长 · 波形曲线

阳气随十二消息卦起伏如正弦波形：横轴为农历十二月（子—亥），纵轴为阳气盛衰；复·剥近谷底（冬至一阳生），乾为峰顶，坤为谷底。卦点即当下，随节而移。

当下之卦＝环上连续六爻：复（一阳生）→ 临 → 泰 → 大壮 → 夬 → 乾（六阳纯阳）→ 姤（一阴生）→ 遁 → 否 → 观 → 剥 → 坤（六阴纯阴），周而复始——冬至一阳生，夏至一阴生。材质取用循阴阳消长：阳气盛时宜取水行材质调和，阴气盛时宜取火行材质补益（传统文化象征，供参考）。

THE EIGHT TRIGRAMS · 八卦图鉴

一石一卦，卦是你的当下

八卦有先天（伏羲）与后天（文王）之分——先天为体、后天为用。后天八卦五行：乾兑属金、震巽属木、坎属水、离属火、艮坤属土；卦象为传统文化符号，用于观照当下、自省自励。

THE RITUAL · 净石仪式

净石 · 请愿 · 随身

月光与白水晶簇，是最安全的净化方式——清空又充能。给石头和自己，一次安静的重启。

壹

净石

晴朗夜晚放窗边照一晚月光，或放白水晶簇上几小时。怕晒的别晒、怕水的别泡、手链少碰盐。

贰

请愿

在白桦树皮上写下心愿（桦皮书），与晶石一同供奉。心念注入，它是你的能量伙伴。

叁

随身

佩戴或陈列，让它与你相伴、记得你的心愿。净化，是水晶与自己的定期保养。

净化频率：天天贴身戴 1～2 周一次 · 压力大、情绪起伏多 每周一次 · 收藏很少戴 一两个月一次 · 新水晶首次 净化一整晚再戴。

CRYSTAL CARE · 净化保养指南

把水晶想成一个杯子

净化是清空，充能是加满。月光与白水晶簇一起做；流水、烟熏、海盐主要只清空——先清空，再充能。

新手安全首选：🌙 月光 与 💎 白水晶簇 —— 清空、充能一起做，几乎对所有水晶都不会出错。

以上为传统文化与民俗象征体系，供参考。水晶是美丽的天然饰品与正向陪伴，不替代医疗与理财建议。
